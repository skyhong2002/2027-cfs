## 本版採用的常規判斷

- 沿用穩定的品項 ID，方便日後接回結構化資料；內容改成今年的候選合作構想，未確認條件以待確認呈現。
- A–D 是介面討論代號，卡片的合作方向是收集需求的提示，不是正式級別或權益承諾。
- 維持照片原有呈現方式，不加逐張年份或情境說明。新取用照片的署名與授權集中在影像來源頁；這不是本屆已舉辦活動的宣稱。這是使用者最後修正後的照片處理方式。
- 聯絡使用產生草稿、開啟郵件程式、複製文字，確保不向未確認的舊表單送資料。寄送由使用者在自己的郵件程式完成，頁面不會宣稱已送達。
- 合作清單只儲存選項 ID 與築夢意願於瀏覽器；姓名、Email、單位與信件內容不寫入 localStorage。
- 全部價格未確認時顯示「待確認」，不顯示零元；已知小計也不代表完整合作金額。
- 試算表同步在任何圖片／JSON 寫入前驗證，不接受未佐證價格、權益與過年度內容。
